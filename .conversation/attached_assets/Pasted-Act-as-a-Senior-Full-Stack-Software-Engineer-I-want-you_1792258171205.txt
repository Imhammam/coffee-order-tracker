Act as a Senior Full-Stack Software Engineer. I want you to build a complete, end-to-end MVP for a Real-Time Coffee Shop Order Tracking & Notification System from A to Z.

### 1. SYSTEM OVERVIEW & ARCHITECTURE
Build a unified, single web application (Centralized System) serving three main user perspectives in real-time using ASP.NET Core Web API, SignalR, and a modern responsive Frontend (HTML5/TailwindCSS/JS or Razor Pages):

1. Cashier Dashboard (Desktop/Tablet View)
2. Kitchen/Barista Display System - KDS (Kitchen Tablet View)
3. Customer Mobile Web App (Mobile Browser View triggered via QR Code)

---

### 2. CORE WORKFLOW & DATA FLOW
1. Cashier enters items for an order and clicks "Create Order & Generate QR".
2. System saves the order, assigns a unique short Order Number (e.g., #101), generates a dynamic QR Code containing the link `http://<domain>/order/{orderId}`, and displays it on screen.
3. Customer scans the QR code with their mobile phone (iOS/Android). No app installation required.
4. Customer page opens via WebSockets (SignalR), displaying:
   - Order Number
   - Itemized Order Summary
   - Real-time Order Status Progress Bar (Pending -> In Preparation -> Ready for Pickup)
   - "Enable Sound / Notifications" interaction button (to bypass mobile audio autoplay policies).
5. Kitchen/Barista screen updates instantly showing the new pending order.
6. Barista changes order status:
   - "In Prep": Customer screen status bar updates in real-time.
   - "Ready": Customer phone triggers an audible alert chime, vibration/visual pop-up, and screen status updates to "Ready for Pickup!".

---

### 3. TECH STACK REQUIREMENTS
- Backend: ASP.NET Core 8.0 / 9.0 Web API + SignalR Hub (`OrderHub.cs`).
- Database: SQLite or In-Memory Entity Framework Core (for quick execution in Replit).
- Frontend: Responsive Web App (Tailwind CSS, Vanilla JavaScript with @microsoft/signalr client, QRCode.js library for dynamic QR rendering).
- Real-Time Protocol: SignalR WebSockets (with Web Push or browser audio alert fallback).
